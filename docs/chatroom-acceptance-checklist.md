# 群聊插件回归验收清单

提交或部署前，必须使用本地 Harness 实际加载的生产构建逐项验收。只有网页上可观察到的结果才能勾选；单元测试不能替代网页验收。

2026-09-01 使用 `http://127.0.0.1:3092/` 的生产构建完成本轮阻断验收。验收时父群与原生分支页面保持同时在线，以覆盖长连接竞争；关闭分支、切换分支、分支发送、主群发送和侧栏折叠均在页面中实际操作。

同日完成搜索与消息 UI 回归验收：用户名、群聊名、主群/分支/私聊正文均返回可见范围内的结果，主群与分支消息点击后在 100ms 内定位高亮；会议总结、分支抽屉、64 个常用表情、常驻复制操作、顶层群聊计数和轻量 Solo 图标均在生产构建页面中确认。

同日使用更新后的本地生产构建完成紧凑消息验收：主群检测到 4 组连续发言并正确标记首尾，纯 URL 具有真实链接且腾讯文档卡片可见；私聊不再显示独立关闭按钮，从私聊点击当前群聊或 Solo 都会直接退出私聊并恢复目标会话。Chromium 盒模型测试同时确认连续气泡圆角、隐藏的重复头像，以及操作/时间同行在聚焦或悬停时展开。

随后按实际使用反馈收紧验收：私聊复用群聊的回复、复制、贴表情、转发和多选组件；已选中的同一群聊也能从私聊直接切回。URL 消息先独立显示，异步取得真实网页标题后才追加腾讯文档卡片，失败不出现占位卡片。连续消息组默认只显示末条操作栏，悬停中间消息时在组内交换唯一操作栏，消息流总高度保持不变。

生产回归补验：原生主群消息不再给每个消息框写入独立的常显操作栏标记，连续消息组由宿主消息流统一保留一条控制栏；悬停首条或中间消息时控制栏随悬停目标切换，离开后恢复到末条。目标生产群的“无需 @AI 自动回复”开关保持开启，普通直呼 AI 的消息会进入判断模型，显式 `@DeepSeek` 仍直接唤醒。

本次收口重新加载最终生产构建复验：Alice 私聊可见回复、复制、点赞、转发、表情和快速会议，随后单击仍处于选中态的“AI 聊天室”即可直接切回；现有腾讯文档 URL 始终可点击，元数据失败时没有“腾讯文档”占位卡片；原生两条连续消息组在空闲态和悬停首条时高度均为 132.5px，唯一操作栏分别位于末条和首条。

最终生产构建再次重启后完成非写入复验：Alice 私聊仍显示与群聊一致的回复、复制、点赞、转发、表情和快速会议控件，单击已选中的“AI 聊天室”可直接切回。忙碌队列的运行时语义、操作接口和 Chromium 布局门禁全部通过。

获得本地消息发送授权后，使用生产构建的两个独立连接完成忙碌队列终验：第二条普通消息在 218ms 内提交，两个连接立即收到相同消息 ID 的气泡；状态从“正在判断”转为无需回复，当前回复结束后该气泡作为普通持久消息保留且没有启动新回复。三个明确提及 AI 的排队气泡分别在 126–266ms 内提交，引导、编辑和撤回接口均返回成功，另一连接同步看到气泡进入引导或消失；编辑返回原文，撤回没有被模型领取。运行时测试固定“问题 A → 回答 A → 问题 B → 回答 B”，Chromium 可见组件测试固定气泡位于当前回答之后、发送者拥有操作控件且其他成员只能查看状态。

## 主群消息

- [x] 点击发送后，文字消息立即出现在主群，已经成功发送的草稿同时清空。
- [x] 主群消息只进入主群，不会出现在已打开的分支中。
- [x] 关闭分支后，主群输入框仍可正常发送。

## 分支生命周期与消息隔离

- [x] 从根消息的分支摘要打开分支时，能够加载原生历史和输入框。
- [x] 在分支发送消息后，分支草稿清空，消息只追加到当前分支。
- [x] 分支消息绝不能出现在父群主时间线中，只能出现在对应分支摘要中。
- [x] 关闭当前分支后，分支面板消失，父群选择不发生变化。
- [x] 关闭一个分支后再打开另一个分支，加载的是新选择的分支，而不是旧分支。
- [x] 新打开的第二个分支可以继续发送隔离消息。
- [x] 重新打开第一个分支时，只恢复第一个分支自己的历史，不出现第二个分支的消息。
- [x] 从侧栏直接打开原生分支 Session 时，即使此前没有打开父群，也能加载历史。

## 侧栏分支投影

- [x] 每个群默认只展示最近更新的两个分支；本轮显示“展开其余 5 个分支”。
- [x] “展开其余 N 个分支”能展示全部旧分支，“收起”能恢复只展示两个，且刷新重绘不会立即丢失展开状态。

## 消息与输入体验

- [x] 群聊、分支和私聊的表情面板提供扩充后的完整常用表情集，并能把选中的表情插入当前草稿。
- [x] 主群、分支和私聊中每个可操作消息块的“回复”旁都有常驻复制按钮；复制文本、Markdown、文件或卡片描述后给出成功反馈。
- [x] 会议结束后生成的总结以标准消息块进入原会话，能够复制、引用、转发和多选。

## Agent 忙碌时的消息队列

- [x] 当前 Agent 正在回复时，第二条人类消息无需等待自动回复判断，发送后立即出现在当前答案之后；另一个已连接页面也立即看到相同气泡。
- [x] 自动回复判断尚未完成时，原消息气泡保持原位并显示“正在判断是否需要 AI 回复”；发送者可见“引导 / 编辑 / 撤回”，其他成员只能看到消息和状态。
- [x] 判断为无需 AI 回复时，只移除气泡的 AI 状态和排队控件；当前答案不停止、不转向，消息不移动，也不启动新一轮 AI 回复。
- [x] 判断为需要 AI 回复或明确提及 AI 时，同一气泡原位切换为“正在排队 · 等待当前回复完成”，页面不重复显示 Harness 原生队列；最终顺序为“问题 A → 回答 A → 问题 B → 回答 B”。
- [x] 点击气泡“引导”后，原消息进入当前 Agent 回合，气泡显示正在引导且不产生重复消息。
- [x] 点击气泡“编辑”后，消息在模型领取前从所有页面撤回，原文恢复到当前输入框，允许修改后重新发送。
- [x] 点击气泡“撤回”后，消息从所有页面消失，且不进入当前或下一轮模型上下文。
- [x] 自动回复判断只改变 AI 接纳状态，不阻塞消息广播；判断缓慢、失败或误判时，参与者聊天仍可连续发送和同步。

## 分支抽屉与侧栏视觉

- [x] 分支抽屉在桌面宽度下不遮挡自身内容、不产生横向溢出，消息、执行过程和输入框布局与主群一致。
- [x] 点击分支抽屉外的遮罩关闭当前抽屉；点击抽屉内部、输入框和消息操作不会误关闭。
- [x] 关闭分支后能继续打开任意其他分支并发送消息，主群也仍可发送。
- [x] “群聊”文件夹数量只统计顶层群聊，不计入任何分支；父群“分支 N”仍只统计该群的真实分支。
- [x] Solo 会话使用低视觉重量的图标，尺寸、底色和对比度均不抢过会话标题。
