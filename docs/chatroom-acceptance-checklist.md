# 群聊插件回归验收清单

提交或部署前，必须使用本地 Harness 实际加载的生产构建逐项验收。只有网页上可观察到的结果才能勾选；单元测试不能替代网页验收。

2026-09-01 使用 `http://127.0.0.1:3092/` 的生产构建完成本轮阻断验收。验收时父群与原生分支页面保持同时在线，以覆盖长连接竞争；关闭分支、切换分支、分支发送、主群发送和侧栏折叠均在页面中实际操作。

同日完成搜索与消息 UI 回归验收：用户名、群聊名、主群/分支/私聊正文均返回可见范围内的结果，主群与分支消息点击后在 100ms 内定位高亮；会议总结、分支抽屉、64 个常用表情、常驻复制操作、顶层群聊计数和轻量 Solo 图标均在生产构建页面中确认。

## 主群消息

- [x] 点击发送后，文字消息立即出现在主群，已经成功发送的草稿同时清空。
- [x] 主群消息只进入主群，不会出现在已打开的分支中。
- [x] 关闭分支后，主群输入框仍可正常发送。

## 分支生命周期与消息隔离

- [x] 从根消息的分支摘要打开分支时，能够加载原生历史和输入框。
- [x] 在分支发送消息后，分支草稿清空，消息只追加到当前分支。
- [x] 分支消息绝不能出现在父群主时间线中，只能出现在对应分支摘要中。
- [x] 关闭当前分支后，分支面板消失，父群选择不发生变化。
- [x] 关闭一个分支后再打开另一个分支，加载的是新选择的分支，而不是旧分支。
- [x] 新打开的第二个分支可以继续发送隔离消息。
- [x] 重新打开第一个分支时，只恢复第一个分支自己的历史，不出现第二个分支的消息。
- [x] 从侧栏直接打开原生分支 Session 时，即使此前没有打开父群，也能加载历史。

## 侧栏分支投影

- [x] 父群的“分支 N”与当前实际渲染的唯一分支行数量一致；本轮网页数据为 7 个分支。
- [x] 每个群默认只展示最近更新的两个分支；本轮显示“展开其余 5 个分支”。
- [x] “展开其余 N 个分支”能展示全部旧分支，“收起”能恢复只展示两个，且刷新重绘不会立即丢失展开状态。

## 分支复用群聊组件

- [x] 分支输入框包含表情、附件、模型、权限和快速会议。
- [ ] 分支 Agent 运行时显示停止按钮，点击后能够停止当前运行。
- [x] 分支中已经完成的思考与工具过程会像主群一样自动折叠。
- [ ] `chatroom_capabilities` 在分支中返回最近消息坐标时不再触发输出 schema 错误。
- [ ] 普通分支消息遵循父群的自动回复策略；明确输入 `@AI` 时一定唤醒分支 Agent。

## 持久聊天行为

- [ ] “新会话”保留可见群聊历史，并把分割线持久留在下一条消息之前。
- [ ] 只有发送者可以撤回；各端同步墓碑，后续模型上下文排除被撤回内容。
- [ ] 刷新后仍保留群聊、分支、消息、分割线、表情、文件卡片、会议卡片和撤回状态。

## 全局搜索与定位

- [x] 点击侧栏搜索按钮打开独立搜索弹窗，不挤压或替换当前会话。
- [x] 搜索结果覆盖用户名、群聊名、分支名、私聊名以及群聊、分支、私聊消息正文。
- [x] 点击用户结果打开对应私聊；点击会话或消息结果打开对应会话，并把目标消息滚动到视口中央且短暂高亮。
- [x] 清空关键词、关闭弹窗并重新打开时，当前聊天和分支状态不丢失。

## 消息与输入体验

- [x] 群聊、分支和私聊的表情面板提供扩充后的完整常用表情集，并能把选中的表情插入当前草稿。
- [x] 主群、分支和私聊中每个可操作消息块的“回复”旁都有常驻复制按钮；复制文本、Markdown、文件或卡片描述后给出成功反馈。
- [x] 会议结束后生成的总结以标准消息块进入原会话，能够复制、引用、转发和多选。

## 分支抽屉与侧栏视觉

- [x] 分支抽屉在桌面宽度下不遮挡自身内容、不产生横向溢出，消息、执行过程和输入框布局与主群一致。
- [x] 点击分支抽屉外的遮罩关闭当前抽屉；点击抽屉内部、输入框和消息操作不会误关闭。
- [x] 关闭分支后能继续打开任意其他分支并发送消息，主群也仍可发送。
- [x] “群聊”文件夹数量只统计顶层群聊，不计入任何分支；父群“分支 N”仍只统计该群的真实分支。
- [x] Solo 会话使用低视觉重量的图标，尺寸、底色和对比度均不抢过会话标题。

## 本轮回归阻断项

- [x] 主群普通消息可发送并即时显示，不会进入当前分支。
- [x] 分支普通消息可发送并即时显示，不会进入父群；关闭后重开仍可发送。
- [x] 分支完成后的思考和工具过程自动折叠，表情、附件、快速会议、模型、权限与停止入口仍存在。
- [ ] 分支抽屉、搜索弹窗、群管理和设置弹窗的层级互不遮挡，Esc 和各自关闭按钮只关闭最上层界面。
